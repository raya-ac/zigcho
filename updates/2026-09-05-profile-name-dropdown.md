# zigcho release 2.7.1

the boxed history button was too much. previous names now sit behind a small chevron to the right of your name, like Steam's alias dropdown.

click it for a compact "also known as" list. dates are still available on hover, and keyboard access, Escape and outside-click dismissal stay intact. it only appears on the profile itself, and only when there is name history to show.

this is a website-only hotfix. no account data, scores, pp or client downloads change.
