# zigcho has its own licence now

zigcho itself is no longer MIT from this version forward. anyone can still run it publicly, use it in production, change it, fork it and pass source or builds around for free.

the rules are simple: keep the zigcho credit, link back to the real repo, say what you changed and do not pretend the original work is yours. you cannot sell it, charge people for access, bury it in a paid plan or relicense it as something else without my written permission. free public servers and normal optional donations are fine.

the private anticheat is deliberately separate. it has its own access licence, stays confidential and cannot be accessed or used without explicit permission. having a copy or being added to the repo is not a public licence.

the third-party file now properly names the pinned osu! client, every direct PP dependency, SQLite, libpq and the asset boundary. client packages also stopped calling zigcho's licence MIT. old copies that were already released under MIT keep those old terms because a new licence cannot rewrite history.
